# 🏰 Темная Башня (Dark Tower) — Agent & Developer Guide

> **Для AI-агентов и разработчиков:** этот документ содержит полное архитектурное описание проекта, модель данных, особенности верстки и правила модификации кода. Читайте его в первую очередь, чтобы мгновенно понять устройство кодовой базы без необходимости анализировать тысячи строк кода.

---

## 1. Обзор проекта и архитектура

* **Что это:** Интерактивный заполняемый лист персонажа (Character Sheet) и встроенный справочник правил под настольно-ролевую игру **«Темная Башня»** (6-я редакция, сеттинг темного фэнтези).
* **Стек:** Pure Frontend (HTML5, Vanilla CSS3, Vanilla JS ES6+).
* **Зависимости:** **0 внешних библиотек** (без React, Vue, jQuery, Tailwind, Bootstrap или Node.js сборщиков). Только Google Fonts (Cinzel, MedievalSharp, Lora) через CDN.
* **Работа в офлайне:** 100% работоспособен автономно без интернета при открытии через `index.html` или `start.bat`.
* **Хранилище данных:** `localStorage` браузера (`tb_character_sheet_v1`). Никакого бэкенда или БД не требуется.

## 3. Модель данных (Data Model)

Состояние приложения хранится в глобальном объекте `AppState` и сериализуется в `localStorage`:

```javascript
const AppState = {
  characters: [ /* массив объектов персонажей */ ],
  activeCharId: 'char_xxx',
  theme: 'dark' // 'dark' | 'parchment' | 'paper'
};
```

## 4. Ключевые подсистемы и логика (`app.js`)

### 1. Автосохранение и реактивность
* Функция `saveState()` сохраняет `AppState` в `localStorage` при любом `input` / `change` событии.
* `renderSheet()` перерисовывает все блоки активного героя.

### 2. Трек ОЗ атрибутов (20 делений)
* В оригинале для каждого атрибута есть 20 квадратов ОЗ (2 ряда по 10).
* Пороги: кости `d4`, `d6`, `d8`, `d10`, `d12`, `d20` имеют фиксированные максимумы.
* Клетки выше текущего `maxHp` получают класс `.is-disabled`.
* Клетки на ключевых порогах (4, 6, 8, 10, 12, 20) подсвечиваются классом `.is-threshold`.
* Клик по клетке отмечает урон `damaged = val`. Повторный клик снимает последнюю отметку.

### 3. Трекер прочности (Durability Boxes)
* **Броня и Оружие:** 10 делений (2 ряда по 5 квадратов 12×12px).
* **Щит:** 8 делений (2 ряда по 4 квадрата 12×12px).
* Функция `renderDurabilityBoxes(container, max, damaged, type, idx)` делит `max` на `Math.ceil(max / 2)` и генерирует `row1` и `row2`.
* **ВАЖНО ДЛЯ ВЕРСТКИ:** контейнер `.durability-boxes` обязан иметь `display: flex; flex-direction: column; gap: 3px;`, чтобы ряды располагались **друг под другом**, а не в одну длинную 10-элементную строку.

### 4. Интерактивная сетка инвентаря (25×10)
* Сетка состоит из 250 ячеек: `col = idx % 25`, `row = Math.floor(idx / 25)`.
* **Выделение прямоугольником:** mousedown фиксирует якорный индекс, mouseenter вычисляет границы `[minRow..maxRow, minCol..maxCol]`.
* **Размещение предмета:** кнопка `[ 🏷️ Подписать ]` сохраняет имя предмета и массив ячеек `cells` в `char.inventory.items`. В ячейке с наименьшим индексом рендерится метка `.grid-cell-label`.
* **Быстрое добавление:** кнопка `[ ➕ Предмет (Ш×В) ]` автоматически находит свободное прямоугольное пространство на сетке и размещает предмет.
* **Удаление отдельного предмета:** 
  1. Выделить предмет на сетке и нажать `[ 🗑️ Удалить предмет ]`.
  2. Кликнуть правой кнопкой мыши (ПКМ) по предмету на сетке для быстрого удаления с подтверждением.

### 5. Дайсроллер (`performRoll`)
* Поддерживает: d4, d6, d8, d10, d12, d20.
* Режимы: Обычный бросок, Преимущество (бросок 2d, выбирается максимальный), Помеха (бросок 2d, выбирается минимальный).
* Анимация результата и лог бросков в модальном окне.
* Кнопки 🎲 на листе (рядом с атрибутами, костью брони, щитом и уроном оружия) автоматически вызывают роллер с соответствующей костью.

### 6. Мастер создания персонажа (Wizard)
* Пошаговый мастер генерации героя по официальным правилам:
  * **Шаг 1:** Имя, концепция, раса (автоматически применяются расовые особенности).
  * **Шаг 2:** Распределение стартовых костей (`d6, d8, d8, d10`) по 4 атрибутам с валидацией пула.
  * **Шаг 3:** Выбор навыков (стартовые 2 навыка + расовые бонусы).
  * **Шаг 4:** Стартовое снаряжение на 100 Динаров.

## 5. Система тем оформления (`style.css`)

Темы переключаются через атрибут `data-theme` на теге `<body>`:
1. `data-theme="dark"` (по умолчанию): глубокая тёмная палитра (#121316), золотые акценты (#d4a34b), бордовые маркеры урона (#a62b2b).
2. `data-theme="parchment"`: тёплые тона состаренного пергамента (#e8dec8).
3. `data-theme="paper"`: **аутентичный бумажный стиль 1:1 под скан.** Фон строго `#ffffff`, рамки и текст `#000000`, маркеры урона `#000000`. При правках стилей всегда проверять контраст текста в этой теме!

### Верстка карточек боя (`.row-combat`)
* `.row-combat` использует CSS Grid: `grid-template-columns: minmax(0, 1fr) minmax(0, 1.18fr) minmax(0, 1fr);`.
* **ПРАВИЛО:** Любые поля ввода (`.armor-name`, `.weapon-name`, `#shieldName`) обязаны иметь `min-width: 0; flex: 1;`, чтобы они не выталкивали селекторы костей и кнопки бросков за пределы карточек.

## 6. База данных правил (`data.js`)

Содержит структурированные данные из рулбука `Темная Башня 6.pdf`:
* `RULEBOOK_DATA.races`: Люди, Эльфы, Дворфы, Орки с описанием, бонусами характеристик и расовыми перками.
* `RULEBOOK_DATA.skills`: Все 20 навыков игры с описанием областей применения.
* `RULEBOOK_DATA.perks`: Полный список перков с требованиями, ценой в КМ и механикой.
* `RULEBOOK_DATA.weapons`: База оружия ближнего и дальнего боя (кость урона, дистанция, прочность, спецправила, цена в динарах).
* `RULEBOOK_DATA.armor`: База доспехов и щитов (кости защиты, штрафы к магии, цена).
* `RULEBOOK_DATA.magic`: Дисциплины, формулы расчета сложности заклинаний, эффекты стихий.

## 7. Правила разработки для AI-агентов

1. **Окружение Windows:** Все команды терминала **всегда** должны выполняться через `cmd /c` (например, `cmd /c git status`).
2. **ASCII-безопасность `.bat` файлов:** В Windows батники ломаются при наличии кириллицы в UTF-8. **Всегда сохраняйте `.bat` файлы исключительно в кодировке ASCII** (текст только на английском языке).
3. **Сохранение разметки печати:** Блок `@media print` в `style.css` настроен на идеальную печать А4 в 1 страницу. Не добавляйте туда глобальные `margin` или сторонние цветные фоны.
4. **Не ломайте `min-width: 0`:** В CSS Grid дочерние элементы по умолчанию имеют `min-width: auto`. Если добавляете новые поля ввода в карточки, всегда указывайте `min-width: 0;` или `box-sizing: border-box;`.
5. **Favicon:** Запрос `/favicon.ico` перехватывается в `server.py`, а иконка лежит в корне. Не удаляйте `favicon.ico`, чтобы избежать ложных ошибок 404 в консоли.
