# Темная Башня — Интерактивный бланк персонажа (НРИ)

Веб-приложение с интерактивным заполняемым бланком персонажа под настольно-ролевую игру **«Темная Башня»**. Бланк воссоздан с точностью 1:1 по оригинальному макету листа и интегрирован с полной базой правил, оружия, брони, перков и заклинаний.

---

## 🚀 Быстрый запуск

1. **Самый простой способ**: дважды кликните по файлу **`start.bat`**.
   - Он запустит локальный сервер на Python и автоматически откроет страницу в вашем браузере по адресу `http://localhost:8080/index.html`.
2. **Без сервера**: просто откройте файл **`index.html`** в любом современном браузере (Chrome, Edge, Firefox, Opera, Safari). Приложение работает полностью автономно и офлайн!

---

## ⚔️ Основные возможности

### 1. Точное воспроизведение оригинального бланка
- **Шапка героя**: Имя, Раса (Люди, Эльфы, Дворфы, Орки, Кастомная), Концепция, Кости Мощи (КМ), Динары (⌘, старт 100), Описание с поддержкой **загрузки арта/портрета героя** (автоматическая оптимизация, сохранение в файл и печать).
- **Атрибуты и здоровье**:
  - 4 атрибута: *Телосложение, Интеллект, Эмпатия, Дух*.
  - Выбор кости: *d4, d6, d8, d10, d12, d20*.
  - Интерактивный трек из 20 квадратов ОЗ с ключевыми серыми порогами (*4, 6, 8, 10, 12, 20*). Активные ячейки динамически адаптируются под выбранную кость атрибута.
  - Клик по квадратам отмечает полученный урон. Снизу отображается текущее здоровье.
  - Кнопки 🎲 рядом с атрибутами для мгновенных проверок.
- **Шрамы**: свободное поле для отметок тяжелых ранений, увечий и психотравм.
- **Навыки**: текстовое поле + модальное окно быстрого выбора всех 20 навыков из книги правил (с возможностью броска 2d20).
- **Перки**: таблица с динамическим добавлением строк, автоматическим расчетом потраченных КМ и каталогом всех перков из книги правил.
- **Снаряжение**:
  - Полноразмерная интерактивная **клетчатая сетка (25×10 ячеек)** с возможностью выделения мышью блоков ячеек (например, 2×8) и **подписи предметов** (Лук, Щит, Меч, Доспех и др.). Названия отображаются прямо на сетке и экспортируются в PDF!
  - Кнопка быстрого размещения предмета по размерам `[ ➕ Предмет (Ш×В) ]`.
  - Клик по предмету на сетке выделяет его для правки или удаления.
  - Режим переключения между графической сеткой и текстовым списком.
- **Защита**:
  - 3 слота брони с типами (Легкая, Средняя, Тяжелая), костью защиты, 10 делениями прочности и спецправилами.
  - Слот щита с костью защиты, 8 делениями прочности (2×4 квадрата), памяткой правил и быстрой кнопкой списания -1 ОП.
  - Каталог пресетов брони и щитов из книги правил.
- **Оружие**:
  - 3 слота оружия с костью урона, 10 делениями прочности, спецправилами и кнопкой броска урона.
  - Каталог пресетов оружия (ножи, мечи, топоры, алебарды, молоты, луки, арбалеты).
- **Магия**:
  - Дисциплины (Пиромантия, Земля, Вода, Воздух, Иллюзии, Некромантия) и привязанные атрибуты.
  - Трекер Аффекта со снятием за 1 КМ.
  - Статус Концентрации.
  - Калькулятор сотворения магии: расчет итоговой сложности с учетом базовой СЛ, помехи от брони, дистанции и аффекта.
- **Заметки**: просторное поле для ведения хроники кампании.

## 🎲 Встроенные инструменты и утилиты

- **Дайсроллер (Бросок костей)**: броски d4, d6, d8, d10, d12, d20 с поддержкой обычного броска, преимущества (2 кости, максимум) и помехи (2 кости, минимум), с историей бросков.
- **Мастер создания персонажа (Wizard)**: пошаговый интерактивный помощник генерации героя по официальным правилам:
  1. Выбор имени, концепции и расы с описанием уникальных расовых бонусов.
  2. Распределение костей `d6, d8, d8, d10` по атрибутам с валидацией.
  3. Выбор стартовых навыков (2 навыка + расовые бонусы).
  4. Стартовое снаряжение на 100 Динаров.
- **Справочник правил (Compendium)**: встроенная книга правил прямо в приложении:
  - *Основные правила* (проверки, сложности, прочность).
  - *Расы* (Люди, Эльфы, Дворфы, Орки с чертами).
  - *Навыки* (все 20 навыков + расовые).
  - *Перки* (полный список с требованиями и ценой в КМ, с кнопкой добавления в 1 клик).
  - *Оружие и броня* (таблицы урона, дистанций и цен).
  - *Магия* (правила, штрафы брони, таблицы заклинаний по стихиям).
- **Магазин снаряжения**: каталог товаров с ценами в динарах (⌘) и кнопкой автоматической покупки с вычетом из кошелька.
- **Темы оформления**:
  - 🌑 *Тёмная тема* — атмосферный темный стиль в духе темного фэнтези.
  - 📜 *Пергамент* — винтажный стиль старинного свитка.
  - 📄 *Лист бланка* — классический черно-белый вид под бумагу.
- **Сохранение и мультиперсонажи**:
  - Автосохранение каждого изменения в `localStorage`.
  - Возможность создавать и переключать несколько персонажей в выпадающем списке.
  - Экспорт персонажа в файл `.json`.
  - Импорт персонажа из `.json`.
- **Печать и экспорт в PDF (А4)**:
  - Кнопка **«Печать / PDF»** автоматически форматирует бланк в чистый, высококонтрастный лист формата А4 без лишних элементов интерфейса, в точности повторяющий оригинальный бумажный бланк.

## 📁 Структура файлов проекта

- `index.html` — разметка бланка персонажа, панель инструментов и модальные окна.
- `style.css` — стили, темы оформления, адаптивная верстка и правила печати на А4 (`@media print`).
- `app.js` — интерактивная логика, состояние, автосохранение, дайсроллер, мастер создания и калькуляторы.
- `data.js` — полная база данных правил, рас, навыков, перков, снаряжения и магии, извлеченная из книги правил.
- `server.py` — локальный сервер для быстрого запуска.
- `start.bat` — командный файл запуска для Windows.
- `update_github.bat` — скрипт автоматической отправки обновлений на GitHub Pages.
- `AGENTS.md` — полное архитектурное руководство для AI-ассистентов и разработчиков.
- `sheet_original.png` — эталонное изображение оригинального бланка.
- `Темная Башня 6.pdf` — оригинальная книга правил игры.
- `ТБ лист персонажа.pdf` — оригинальный PDF-бланк.
